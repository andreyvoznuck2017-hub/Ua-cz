# Свої у Європі — Android 1.1.0

Нативна Android-оболонка для `https://test.jkunis.eu/?app=1&native=android`.

- WebView з JavaScript, cookies, upload, камерою/мікрофоном та геолокацією.
- Завжди підтягує актуальний інтерфейс із сервера без старого WebView-кешу.
- Міст `window.SvoyiAndroid` для майбутніх нативних інтеграцій.
- Остання веб-версія при підготовці: v15.40.4 (ліве вертикальне мобільне меню).
- GitHub Actions збирає installable debug APK як artifact `Svoyi-Europe-APK`.

> Для повноцінних фонових нативних push-повідомлень у закритому застосунку пізніше підключимо Firebase Cloud Messaging.
