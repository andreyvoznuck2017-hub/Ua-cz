# Свої — iPhone 1.0.1 (build 2)

Це iOS-клієнт зі спільним вебінтерфейсом https://test.jkunis.eu/. Сервер та Android/Windows-версії ця гілка не змінює.

## Результат хмарної збірки

`Svoyi-1.0.1-UNSIGNED.ipa` містить ARM64-застосунок для справжнього iPhone, а не вихідні файли чи програму для симулятора. Файл **не підписаний Apple-сертифікатом для встановлення**. Перед встановленням потрібне особисте підписання або підпис команди Apple Developer. Не перейменовуйте файл на SIGNED і не видавайте його за версію TestFlight.

Збірка: `bash ios/Scripts/build-device.sh` на macOS з Xcode, Swift, Node.js та Python 3. Скрипт бере наявну іконку з кореня репозиторію, запускає тести, компілює через Apple SDK, пакує IPA і окремо намагається запустити симулятор. Докази: `ios/build/` в артефактах GitHub Actions.

## Межі версії

Камера, мікрофон, файли, геолокація та вебдзвінки потребують перевірки на фізичному iPhone. APNs push із сервера, відповідь зі сповіщення, аватари сповіщень і фоновий виклик CallKit/PushKit не реалізовані. Локальне тестове сповіщення не є серверним push.

Apple-паролі та сертифікати не додаються у вихідний код. Репозиторій публічний; матеріали підписання допускаються лише у належному захищеному сховищі.
