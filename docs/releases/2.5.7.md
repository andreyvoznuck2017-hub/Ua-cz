# Svoyi 2.5.7 — home and mail

Signed Android APK: `release257/Svoyi-2.5.7.apk`.

Package `eu.svoyi.qa.finish255`, version code 357, minimum Android API 26, target API 35. Package and owner signing certificate are unchanged from 2.5.6; the APK supports an in-place update.

SHA-256: `6fa39453ac4e35e641f348f8c41abb3cfdc6b5b7ec3a9232698218144beeca71`.

## Changes

- Home uses the current server section order, a compact Prague hero, responsive statistics, theme-aware cards, and native previews of groups, chat, posts, jobs, housing, photo battles, market, services, courses and entertainment.
- Post photos and comments retain their routes and original reaction actions. Cover previews use full-width images.
- Mail has one conversation-list heading, compact search, all/unread filters with counts, clearer empty states, message previews and labelled attachment controls.
- The native mail transport, media handlers, drafts, quote/edit actions and lifecycle remain in the existing controller. New presentation labels follow the language returned by the server.

## Build and signing

The change extends the existing native APK. `build.py` is the Linux build; `build.cjs` is the Windows build used on the authorized development PC. Both compile `HomeScreen257.java` and `MailScreen257.java`, inject the new classes and hook exactly three original classes: AppFinish252, Batch20Ui and NativeMailScreen. Unrelated application entries are preserved.

Signing uses the existing owner key on the development PC; the key is not included in this repository. Android apksigner verifies the delivered APK's v2 and v3 signatures across API 26–36, and zipalign passes.

Certificate SHA-256: `8a5a3738f9ff2007825abbe6574afb0bf3a3a9ea33ed4b74e7a6b78332c0012b`.

## Verification

Android 9 / API 28, BlueStacks on the development PC:

- Installation over 2.5.6 succeeds and preserves login.
- Native send, edit and quote are confirmed independently against the server using disposable QA accounts.
- Drafts survive navigation and process restart; inbox search and clear work.
- Group, post-comment, job and market cards open the intended screens.
- Ukrainian Night home, inbox and thread remain readable; the profile theme is restored after the test.
- The final APK passes home and mail language checks; Ukrainian is restored after the test.

The Android 16 / API 36 workflow installs the 2.5.6 baseline, logs in, saves a draft, updates to the exact signed release APK, checks retained state, tests native mail against a second disposable account, and verifies downloaded file/photo attachment bytes. Its checks and screenshots are retained as a workflow artifact.

## Scope

This release updates the native home and mail presentation and preserves the existing native features. Website-only translation and scheduled-mail features are not provided by the current native API. A physical Xiaomi was not connected for this verification; emulator results do not establish success on every physical device.
